# Student Management System

This project has a React frontend and a small Node backend API for saving student details.

## Run

```powershell
npm install
npm run dev
```

Frontend: `http://127.0.0.1:5173`

Backend API: `http://127.0.0.1:5000/api`

## Commands

```powershell
npm run dev
npm run dev:frontend
npm run dev:backend
npm run build
```

## Student Fields

- Student name
- Mail
- Phone no
- Age
- Course
- Address
